# Первый релиз LibreGram: CachyOS

**Первая целевая платформа:** CachyOS / Arch Linux, x86_64.  
**Целевой формат:** нативный пакет pacman `.pkg.tar.zst`.  
**Версия первого пакета:** 0.1.0 preview.

Это план первого выпуска и инструкция локальной сборки. Пока не пройдены чистая сборка, установка и регрессионные проверки, пакет нельзя считать готовым публичным релизом.

## Почему сначала CachyOS

CachyOS основан на Arch Linux и использует pacman/makepkg. Поэтому LibreGram будет собираться из исходников с системными Qt и библиотеками, а устанавливаться как обычный пакет. Один и тот же пакетный формат подходит и для совместимых Arch-based систем, но первая проверка проводится на CachyOS.

## Требования к сборке

- x86_64.
- Актуальная система CachyOS.
- `base-devel`, Git, CMake, Ninja, Python и зависимости, указанные в `packaging/arch/PKGBUILD`.
- Собственные Telegram API `api_id` и `api_hash`.

Сборка использует packaged CMake mode (`DESKTOP_APP_USE_PACKAGED=ON`). В этом режиме клиент подключается к системным библиотекам. Набор зависимостей отличается от контейнерного статического способа, поэтому он требует реальной проверки на целевой системе.

## Быстрая сборка

Полная инструкция находится в [packaging/arch/README.md](../packaging/arch/README.md). Краткий порядок:

1. Клонировать ветку `libregram/dev`.
2. Перейти в `packaging/arch`.
3. Подготовить собственные API credentials в переменных `LIBREGRAM_API_ID` и `LIBREGRAM_API_HASH`.
4. Выполнить `makepkg --syncdeps --clean --cleanbuild`.
5. Установить пакет через `sudo pacman -U`.

Не используйте для публичной сборки credentials от другого проекта. Для LibreGram нужна отдельная пара; она попадёт в бинарный файл и может быть извлечена. Не добавляйте её в PKGBUILD, исходники, issue или CI-логи.

## Условия готовности 0.1.0

- [ ] Подмодули загружаются чистым рекурсивным checkout.
- [ ] PKGBUILD проходит синтаксическую проверку и `makepkg --printsrcinfo`.
- [ ] Полная сборка Release проходит на свежей CachyOS x86_64.
- [ ] Пакет проходит `namcap`, а зависимости проверены по фактическим ELF-библиотекам.
- [ ] Приложение устанавливается и удаляется через pacman.
- [ ] Проверен запуск в KDE Plasma Wayland и X11.
- [ ] Проверены вход в Telegram и базовая отправка/получение сообщений.
- [ ] Проверены создание профиля, отдельный запуск, избранное, группы/метки, архивирование и восстановление.
- [ ] Проверено, что иконки, desktop entry, D-Bus service и системные ссылки используют LibreGram, а не Telegram/Kotatogram.
- [ ] Проверена сохранность пользовательских данных при обновлении пакета.
- [ ] Подготовлены release notes и контрольная сумма пакета.

## Ограничения первого выпуска

- Только Linux x86_64.
- Только нативный пакет Arch/pacman.
- LibreTheme, LibreProxy и Local Premium не должны рекламироваться как готовые, пока их реализации не прошли тесты.
- Автообновление отключено до появления собственного проверенного канала подписи и обновлений.
- Пакет собирается с credentials Telegram-приложения LibreGram. Публичный бинарный пакет допустим только после решения вопроса с отдельной парой credentials и проверки самого релиза.
