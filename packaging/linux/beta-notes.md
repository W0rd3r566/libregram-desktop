LibreGram Desktop 0.1.0 beta 1 has a WS Proxy switch in the main menu, optional proxy startup, a Graphite theme, and a manager for separate local workspaces.

Choose from the available x86-64 assets:

- Arch Linux and CachyOS: install the `.pkg.tar.zst` with `sudo pacman -U ./libregram-*.pkg.tar.zst`.
- Ubuntu and Debian: install the `.deb` with `sudo apt install ./libregram-desktop_*.deb`.
- Other glibc Linux distributions: extract the `linux-x86_64.tar.xz` and run `./LibreGram`. Keep the helper beside it.
- NixOS: see the [Nix instructions](https://github.com/W0rd3r566/libregram-desktop/blob/v0.1.0-beta.1/docs/libregram/install.md).
- Windows: run the `LibreGram-Windows-x86_64.exe` installer when it appears in the assets.
