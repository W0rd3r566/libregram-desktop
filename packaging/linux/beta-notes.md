LibreGram Desktop 0.1.0 beta 2 adds seasonal icon colours and an optional local Premium star next to your own name. It also includes the NixOS Wayland keyboard layout fix.

- Windows x64: choose the installer or extract the portable ZIP and run LibreGram.exe from that folder.
- Arch Linux and CachyOS: install the `.pkg.tar.zst` with `sudo pacman -U ./libregram-*.pkg.tar.zst`.
- Ubuntu and Debian: install the `.deb` with `sudo apt install ./libregram-desktop_*.deb`.
- Other glibc Linux distributions: extract the Linux x86-64 archive and run `./LibreGram`. Keep the WS Proxy helper next to it.
- NixOS x86-64: download the flake or classic recipe and follow the installation guide in that archive.
